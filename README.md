Focal — README
Focal is an AI-powered photography critique and coaching tool.
Live at focalphoto.lovable.app · Read the full case study

What it does

Focal helps photographers understand not just whether a photo works, but why, and what to do differently next time.
Upload a photo, select the principles you want assessed, and receive structured feedback: a punchy verdict followed by a principle-by-principle breakdown with specific improvement advice tailored to how the shot was taken.
Log in to unlock the skills profile: a coaching dashboard that tracks your critique history, identifies recurring patterns, and rates your performance across each principle over time.

The principles

Focal assesses photographs against nine core principles: Composition, Lighting, Framing, Focus, Subject clarity, Colour, Rule of thirds, Leading lines, and Depth and layers.
Users select which principles they want critiqued rather than receiving blanket feedback across all nine.

Key features

Single photo critique with structured, principle-by-principle feedback. Shooting context selector so feedback reflects what was physically possible: selfie, handheld, or tripod. Skills profile with ratings out of 10 per principle drawn from full critique history. Coach callout identifying the single highest-priority area to focus on. Manual profile update triggered by the user when they want a fresh assessment.
